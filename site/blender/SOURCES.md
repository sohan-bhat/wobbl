# Sources and licenses

Every model in site/public/models is built from the Python scripts in this folder with Blender 4.5 LTS. No
model, mesh or texture is copied from anywhere else. The scripts make the shapes themselves, and the textures
below are the only outside files they use. All of them are CC0, so they need no credit, and they are listed here
so a rebuild can be checked.

## Textures from ambientCG

ambientCG publishes its materials under CC0 1.0 Universal (https://docs.ambientcg.com/license/). The build
fetches the 1K JPG set of each one, checks the zip against the SHA256 below and scales the maps down to 512
pixels before they go into a model.

## Made here

The cast skin, paint orange peel, brushed grain, fine grain, tread plate and roughness maps are generated by
lib/looks.py from seeded noise, so they are original to this project and carry the project's own license. The
ambient occlusion in every model is baked from its own geometry in Cycles.

## Tools

Blender 4.5.14 LTS for macOS Intel came from the official mirror list at download.blender.org, checked against the
SHA256 published with the release (613e73339e97bd113adeeb28d9155beeacf2df7119ee4dbd6bdce234843645f6). The models
are compressed with gltfpack 0.24 from meshoptimizer, which is MIT licensed.
