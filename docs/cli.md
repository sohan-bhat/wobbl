# Command line reference

This reference now lives on the website, at
[sohan-bhat.github.io/wobbl/guides/cli](https://sohan-bhat.github.io/wobbl/guides/cli/).

Every command has a page there with its options and real examples, from asking in plain words
with `wobbl part.step "question"` to `wobbl run`, `inspect`, `thermal`, `circuit`, `check`,
`fix`, `materials`, `validate`, `setup`, `doctor`, `uninstall` and `mcp`. The syntax for loads,
supports and face selectors is in the inputs guides, starting with
[loads](https://sohan-bhat.github.io/wobbl/guides/inputs/loads/).
