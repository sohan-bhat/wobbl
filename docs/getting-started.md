# Get started

This guide now lives on the website, at
[sohan-bhat.github.io/wobbl/get-started](https://sohan-bhat.github.io/wobbl/get-started/).

Install it with `npm i -g wobbl`, which brings its own Python, or from PyPI with
`pipx install wobbl` or `uv tool install wobbl` on Python 3.10 or newer. Then `wobbl setup` puts CalculiX and
ngspice into `~/.wobbl` and connects Claude Code, Codex, Cursor and Gemini CLI, `wobbl doctor`
checks every piece, and `wobbl simulate "will a blue LED on 5V with a 47 ohm resistor fry?"` gives a
first answer with no files. The steps have pages of their own for
[installation](https://sohan-bhat.github.io/wobbl/get-started/installation/),
[setup](https://sohan-bhat.github.io/wobbl/get-started/setup/), the
[first run](https://sohan-bhat.github.io/wobbl/get-started/first-run/),
[platforms](https://sohan-bhat.github.io/wobbl/get-started/platforms/) and the
[FAQ](https://sohan-bhat.github.io/wobbl/get-started/faq/).
