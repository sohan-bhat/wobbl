# Fix a failing part

This guide now lives on the website, at
[sohanbhat.me/wobbl/guides/fixing](https://sohanbhat.me/wobbl/guides/fixing/).

`wobbl fix` lists the fixes in a finished strength result, each with the number it needs, and
`wobbl fix --apply` builds the ones it can, fillets and gussets in any STEP file and thickness and
fillet parameters in a parametric part, then solves each version again. On the shelf bracket a
gusset takes the peak from 52.3 to 9.82 MPa. The command itself is on the
[wobbl fix](https://sohanbhat.me/wobbl/guides/cli/fix/) page.
