# Use Wobbl from your agent

This guide now lives on the website, at
[sohan-bhat.github.io/wobbl/guides/agents](https://sohan-bhat.github.io/wobbl/guides/agents/).

`wobbl setup` registers Wobbl's MCP server and installs its skill for Claude Code, Codex, Cursor
and Gemini CLI. The agent then gets 15 tools that return compact JSON with the verdict, the
checks, the confidence and the paths of the heatmaps and the report, and the skill teaches it to
read the checks before the number. Each agent has a page, and so do the
[MCP tools](https://sohan-bhat.github.io/wobbl/guides/agents/mcp-tools/) and the
[skill](https://sohan-bhat.github.io/wobbl/guides/agents/skill/).
