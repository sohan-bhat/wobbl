# Wobbl

Simulate anything before you build it.

Wobbl gives AI coding agents and people a verified way to run real engineering
simulations: structural FEA with CalculiX and gmsh, heat transfer, and circuits
with ngspice. Every answer comes with the number, a heatmap, a confidence level,
the assumptions behind it and a suggested fix.

Work in progress. The full README lands with v0.1.0.
